```bash
# 3. Check logs

```

### Common Issues

**Port already in use**:
```bash
# Find what's using the port
netstat -ano | findstr :2222

# Kill the process or use different port
```

**Dashboard won't start**:
```bash
# Check if Streamlit is installed
pip install streamlit

# Check port 8501
netstat -ano | findstr :8501
```

**No data showing**:
- Wait a few minutes for attacks
- Or generate test data by connecting to honeypot
- Check database: `sqlite3 data/honeypot.db`
